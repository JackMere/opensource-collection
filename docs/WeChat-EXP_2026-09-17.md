## 项目简介

WeChat EXP 是 Windows 平台上的**微信 4.x 聊天记录备份、解密、查看与分析一体化工具**。下载 exe 双击即用，程序自动拉起本机 Web 界面（`127.0.0.1:5000`），所有操作在浏览器中完成。

它的技术核心不在界面，而在**加密层**：微信 4.x 的聊天数据库是 SQLCipher 4 加密的，新版图片又改用了一套只存于运行时内存的逐图密钥机制。项目把这两层都打通了——先取出密钥，再解密数据，最后做统一索引与可视化。

## 核心功能

1. **一键备份**：四阶段管线（扫描账号 → 解密数据库 → 迁移媒体 → 构建索引），支持日期范围与**硬链接增量备份**
2. **聊天查看器**：Flask + Vanilla JS SPA，头像三级加载（CDN 真实头像 → 群聊 2×2 首字组合 → MD5 确定性 SVG），名称五级解析策略，全消息类型渲染（文本/图片/视频/语音/文件/表情/引用回复/小程序卡片/视频号卡片/系统消息）
3. **消息筛选**：日期范围 + 消息类型 + 发送者 + 关键词四维组合
4. **语音转文字**：集成**本地 Whisper**（首次自动下载约 140MB 模型，之后离线转换）
5. **词云分析**：jieba 分词 + 中文停用词系统
6. **年度报告**：Spotify Wrapped 风格，7 张卡（全局概览 / 24×7 作息热力图 / 字数统计 / 回复速度 / 表情宇宙 / 月度挚友榜 / 关键词词云）
7. **综合报告**：ECharts 交互式图表（月度趋势、类型分布、活跃时段、联系人排名、媒体统计）
8. **聊天导出**：TXT / HTML，支持模糊匹配与多结果选择
9. **员工报表**：上传 Excel 批量匹配导出（⚠️ 见注意事项）
10. **垃圾清理**：按聊天空间占用排序，展示图片/视频/文件占比，可预览删除媒体文件（保留文字记录，操作不可逆）
11. **密钥提取**：单独提供密钥提取入口，用于备份时密钥不足的场景

## 技术机制

### ① 数据库密钥提取（`wechat_key_extract.py` / `config_cipher_extract.py`）

微信 4.x 数据库为 **SQLCipher 4** 加密。密钥提取分两代方案：

| 微信版本 | 手法 | 门槛 |
|---------|------|------|
| **4.1.10+**（当前主流） | **只读扫描 `Config.Cipher`** —— 定位进程内存中的 WCDB 密钥配置对象，直接读出全部数据库密钥 | 无需管理员权限、无需退出/重启微信、不受「登录初期密钥窗口期」限制，且能自动跟随微信对数据库的重新加密 |
| < 4.1.10 | 传统内存扫描 | 受密钥窗口期影响，须登录后尽快操作 |

随后以 **AES-256-CBC** 解密数据库（`engine/decrypt.py`）。

### ② V2 图片解密（项目最硬的技术点）

微信 4.x 启用新的图片加密（称 V2），**每张图一把独立密钥，且只存在于程序运行时内存，不落盘**。项目已完整逆向其格式：

```
偏移     大小    内容
0        6       签名 \x07\x08\x56\x32\x08\x07
6        4       AES 数据大小（LE uint32）
10       4       XOR 数据大小（LE uint32）
14       1       填充字节
15       N       AES-128-ECB 加密数据（PKCS7 填充）
15+N     16      常量尾部 56fbf486095aa2eed54a41405dffe35d
15+N+16  M       XOR 加密尾部（密钥 0xC9）
```

**密钥收割三策略**（`v2_key_extract.py`，63 KB）：

| 策略 | 做法 |
|------|------|
| V2 头部邻近扫描 | 搜索内存中所有 V2 魔数，读每个位置 ±256 字节，以 16 字节滑动窗口穷举；要求同一密钥在两个窗口同时命中同一密文，降低误判 |
| `wx_key` 模式定位 | 检测微信版本号，在 Weixin.dll 中搜索版本特定的字节模式，定位图片解密函数地址后读取附近内存 |
| 全内存正则扫描 | 枚举所有可读写内存区域，正则匹配 32 字符 hex 字符串，hex 解码后测试 AES 解密 |

**自动停止条件**：所有 V2 密钥已找到 / 微信退出 / 连续 60 轮无新密钥。

**固有局限**（README 专设一章说明）：只能获取微信**当前已加载到内存**的图片密钥。因此需先在微信里滚动浏览目标聊天，再点「提取密钥」。消息 XML 里的 `aeskey` 属性**不可用**（已验证：CDN 的 aeskey ≠ 本地文件密钥）。

### ③ 系统架构

```
CLI (main.py)          backup │ serve │ export │ harvest-keys
        ↓
Web 层 (web/)          Flask SPA │ SSE 进度 │ REST API │ Blueprints
        ↓
Engine 层 (engine/)    decrypt │ services(chat/message/media/v2_key) │ parsers
        ↓
Backup 管线 (backup/)  scanner → decryptor → migrator → indexer → pipeline
        ↓
外部依赖               SQLCipher 4 │ zstandard │ pycryptodome │ Whisper │ ECharts
```

**分层原则**：Engine 层是核心，被 CLI 与 Web 共享且**不依赖 Flask**；Web 层只做展示与路由；CLI 是最薄入口层。

**工程量集中在逆向与解码部分**：`v2_key_extract.py` 63 KB、`media.py` 67 KB、`engine/services/message/__init__.py` 54 KB、`wechat_key_extract.py` 41 KB、`key_scan.py` 38 KB、`engine/parsers/types.py` 36 KB。

## 安装与使用

```bash
# 普通用户：下载 exe 双击运行
# GitHub Releases → wechat_exp_2.3.20260910.exe
# 启动后自动打开 http://127.0.0.1:5000

# 开发者（从源码运行）
pip install -r requirements.txt
python main.py backup
python main.py serve
```

**命令行参考（节选）**

```bash
wechat_exp.exe backup --days 30                      # 备份最近 30 天
wechat_exp.exe backup --days 0 --wxid <wxid> \
    --link-dest "E:\bak\2026-06-01"                  # 增量备份（硬链接复用媒体）
wechat_exp.exe harvest-keys --interval 2.0           # 收割 V2 图片密钥
wechat_exp.exe serve --port 5000                     # 启动 Web 界面
wechat_exp.exe export -m report                      # 导出综合报告
wechat_exp.exe -q -c 张三                            # 快速打开指定联系人
```
