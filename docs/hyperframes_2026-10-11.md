## 项目简介

HeyGen 开源的确定性视频渲染框架，口号"Write HTML. Render video. Built for agents."：Agent 写 HTML/CSS/动画，框架逐帧渲染成视频。确定性输出恰好 khắc phục AI 生视频的随机性，适合把"代码能力"直接变成"成片能力"。

## 核心功能

1. HTML/CSS/媒体资源 → 程序化视频渲染
2. 为编码 Agent 设计的调用边界（动效包装、确定性输出）
3. 生态联动：video-spec-builder（分镜脚本生成）、html-video 等配套工具

## 使用场景

- 软件更新宣传片、产品演示视频（代码+设计语言复用）
- Agent 自动产出营销/讲解视频
- 与本库 No.16「UI组件库盘点」联动：同一套前端组件既渲染页面又渲染视频

## 优势与注意事项

- 优势：Apache-2.0 商用友好；60K⭐ 社区最活跃的 Agent 视频方案；确定性渲染，质量可控
- 注意：重前端（HTML/CSS/动效）功底；长视频渲染耗时与机器性能相关
