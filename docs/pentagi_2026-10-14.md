## 项目简介

自托管多 Agent 自主渗透测试系统：自然语言描述目标和目的，专家 Agent 团队规划分工，在隔离 Docker 沙箱里调用 nmap、Metasploit、sqlmap 等 20+ 专业工具执行，最后输出带利用指南的漏洞报告。成功经验沉淀进 PostgreSQL+pgvector 供后续任务复用，可选 Neo4j 知识图谱追踪主机/服务/发现。

## 核心功能

1. 全自主+助手引导双模式，多专家 Agent 分工（侦察/开发/基建）
2. 20+ 内置安全工具，沙箱隔离执行
3. 10+ 模型商 + 自定义 OpenAI 兼容端点（可接自建网关）
4. 智能记忆：pgvector 存结果与成功打法；可选 Neo4j 语义图谱
5. Web UI + REST/GraphQL API（Bearer 鉴权）+ Grafana/Prometheus 监控
6. 小模型辅助：执行监控（Beta）与智能任务规划（Beta）

## 使用场景

- 自有平台上线前安全自测（交易网关、报盘接口、仿真环境暴露面）
- 授权渗透测试自动化、报告归档
- 红队辅助：侦察与漏洞验证提速

## 优势与注意事项

- 优势：MIT 可商用；28K⭐ 赛道头部；自托管数据不出境；模型层完全开放可接自建网关控成本
