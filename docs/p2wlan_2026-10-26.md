## 项目简介
P2WLAN 是面向游戏联机、远程访问和跨地域组网的免费开源虚拟局域网软件，为异地设备分配私有虚拟 IP，优先建立局域网/IPv6/IPv4 UDP 直连，直连不可用时自动回退到端到端加密中继。客户端覆盖 Windows、macOS、Linux（含 arm64 CLI）、Android 与 OpenWrt，Control 与 Relay 均可自托管。

## 核心功能
1. 虚拟三层网络：设备拿固定虚拟 IP，SSH/RDP/NAS/Web 面板/数据库按虚拟 IP+端口访问。
2. 直连优先：同一局域网直连，跨网自动试 IPv6 与 UDP 打洞（含对称 NAT 下的端口预测与生日探测）。
3. 加密 Relay 回退：打洞失败自动走 TLS 中继，网络恢复后切回直连。
4. 房间制组网：房间号+密码+房主审批，个人网络与房间网络相互独立。
5. 连接可观测：客户端展示在线设备、Direct/Relay 路径、延迟与收发流量，内置诊断。

## 安装与使用
```bash
# Linux 无桌面环境（CLI + daemon），把 vX.Y.Z 换成实际 Release 标签
P2WLAN_VERSION=vX.Y.Z
curl -fsSL "https://raw.githubusercontent.com/yhan-sun/p2wlan/$P2WLAN_VERSION/scripts/install-linux-cli.sh" -o /tmp/p2wlan-install.sh
sudo sh /tmp/p2wlan-install.sh --version "$P2WLAN_VERSION"

# 配置自托管 Control 并上线
p2wlan config set control https://control.example.com
p2wlan login -u your-name
p2wlan up && p2wlan status
```
图形客户端去 Releases 页下载对应平台安装包；服务端 `server-vX.Y.Z` 是独立发布。部署指南见 `docs/guides/self-hosting.md`。

## 使用场景
- 异地联调/远程开发：SSH、RDP、数据库连接、开发测试机互联。
- NAS/HomeLab 外网访问，不逐个暴露公网端口。
- 朋友联机（Minecraft/Terraria）与跨地域（家庭宽带/校园网/云主机）组网。

## 优势与注意事项
- 优势：全端 MIT（含服务端源码）；打洞策略比 Tailscale 官方更激进（双端对称 NAT 不直接放弃）；房间制适合按项目隔离网络；有 arm64 CLI 包。
- 注意：三层 TUN 网络，无二层广播桥接（依赖局域网广播发现的服务接不上）；新安装不预填 Control，必须自建或信任管理员；项目仅 3 个月，成熟度低于 Headscale/Nebula，先试点；加密非国密算法，国密合规场景不适用；Relay 带宽与服务器费用由部署者承担。
