## 项目简介

Headroom 是一个 AI Agent 上下文压缩层，在工具输出、日志、文件、RAG 检索块等数据到达 LLM 之前进行智能压缩。它提供三种运行模式：**Library（库）**、**Proxy（代理）**、**MCP Server（MCP服务器）**，支持本地优先、内容感知压缩、可逆还原。

## 核心功能

1. **智能压缩**：对 JSON 数据节省 60-95% token，对编码代理节省 15-20% token
2. **三种运行模式**：
   - **Library**：作为 Python/TypeScript 库直接集成
   - **Proxy**：作为 HTTP 代理层，拦截并压缩工具输出
   - **MCP Server**：标准 MCP 协议，无缝接入 Claude Code、Cursor 等工具
3. **内容感知压缩器**：针对不同数据类型（JSON、日志、代码、文本）有专门的压缩策略
4. **可逆压缩**：压缩后的数据可还原，不影响 LLM 理解
5. **本地优先**：数据不经云端，隐私安全
6. **自带 AI 模型**：集成 Kompress-v2-base 压缩模型

## 安装与使用

```bash
# Python 库
pip install headroom-ai

# MCP 服务器模式
npx headroom-ai mcp

# 代理模式
headroom proxy --port 8080
```

## 使用场景

1. **AI 编码工具**：减少 Claude Code、Cursor 等工具中工具输出的 token 消耗
2. **RAG 应用**：压缩检索到的文档块，在上下文窗口内放入更多相关信息
3. **日志分析**：压缩大型日志文件，让 LLM 能处理更多日志数据
4. **JSON 处理**：压缩 API 响应、配置等 JSON 数据，大幅降低 token 消耗
5. **多 Agent 协作**：在 Agent 间传递压缩后的上下文信息

## 优势与特点

### 优势
- 大幅节省 token 成本（尤其 JSON 数据场景）
- 三种模式灵活适配不同场景
- 本地运行，数据不出本地
- 社区活跃（61K+ Star，活跃维护）
- 文档完善，安装简单

### 注意事项
- 压缩有一定计算开销，需权衡压缩耗时 vs token 节省
- 极少数场景下压缩可能影响 LLM 对数据的精确理解
- 需要 Python 3.10+ 或 Node.js 18+ 运行环境
