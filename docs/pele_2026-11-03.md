## 项目简介

Pele 是一个把 Mermaid 图渲染成 SVG 的 TypeScript 库，由 Obsidian 团队开源（2026-10）。它的定位是「又小又快的 Mermaid 渲染器」：同步渲染、无运行时依赖、颜色和字体全部走 CSS 变量，因此能随主题切换即时变色，不需要重新渲染。

支持 **Mermaid 12.1.0 内置的全部图表类型**（流程图、时序图、类图、状态图、甘特图、饼图、思维导图等）。既可以在浏览器里 `mount()` 到 DOM 节点，也可以在 Node 环境里 `render()` 直接产出 SVG 字符串。

## 核心功能

1. **同步渲染**：`render(text)` 立即返回 `{ svg }`，没有 async/await 的等待链路，适合构建时批量出图。
2. **零运行时依赖**：不依赖 d3、不依赖 Mermaid 本体，打包体积可控。
3. **CSS 变量主题**：`--pele-bg`、`--pele-fg`、`--pele-line`、`--pele-accent`、`--pele-font`、`--pele-radius` 等变量控制配色与字体；`--pele-series-1` 至 `--pele-series-8` 控制图表系列色。
4. **按需加载**：主入口包含全部图表类型；可用 `pele/core` + `pele/diagrams/flowchart` 只注册需要的类型来减小初始包体，或用 `pele/lazy` 的 `renderAsync()` 动态加载。
5. **自适应容器**：浏览器端 `mount(el, text)` 会读取 CSS 字体，并按容器宽度调整布局。
6. **安全处理**：转义图表文本、过滤链接与样式、限制输入与输出体积，可用于渲染不可信来源的 Mermaid 源码。

## 安装与使用

```bash
npm install pele
```

浏览器直接 CDN 引入：

```html
<script src="https://cdn.jsdelivr.net/npm/pele@1/dist/pele.global.js"></script>
<script>
  for (const el of document.querySelectorAll('pre.mermaid')) pele.mount(el, el.textContent);
</script>
```

Node / 构建产物里出 SVG：

```ts
import { render } from 'pele';

const { svg } = render(`flowchart LR
  A[Mermaid text] --> B[SVG]`);

document.querySelector('#diagram').innerHTML = svg;
```

只注册需要的图表类型（减小体积）：

```ts
import { register, render } from 'pele/core';
import flowchart from 'pele/diagrams/flowchart';

register(flowchart);
```

主题定制：

```css
.pele {
  --pele-bg: #ffFcf0;
  --pele-fg: #100f0f;
  --pele-muted: #6f6e69;
  --pele-line: #100f0f;
  --pele-surface: #f2f0e5;
  --pele-surface-alt: #e6e4d9;
  --pele-border: #cecdc3;
  --pele-accent: #205ea6;
  --pele-font: sans-serif;
  --pele-radius: 4px;
}
```

## 使用场景

- **知识库 / 文档站**：把 Markdown 里的 Mermaid 代码块渲染成 SVG，替代体积庞大的 Mermaid 本体。
- **构建期出图**：CI 里批量把架构图、流程图转成静态 SVG，随页面一起发布，浏览器端零 JS。
- **支持明暗主题的界面**：颜色由 CSS 变量驱动，切主题不用重绘图表。
- **渲染用户输入的图**：内置文本转义与大小限制，比直接塞 Mermaid 更可控。
- **Obsidian 生态**：与 Obsidian 的 Markdown 写作流程天然契合（同团队出品）。

## 优势与注意事项

**优势**
- 体积小、无依赖、同步 API，接入成本低。
- 主题切换零重绘，适合暗色模式。
- 官方维护，文档与 playground 齐全（pele.run）。

**注意**
- 只做「Mermaid → SVG 渲染」，不是 Mermaid 的替代品：依赖 Mermaid 12.1.0 的语法，超出该版本的语法特性可能不支持。
- 与 Mermaid 官方渲染器在**样式细节**上不完全一致（默认字体、间距、箭头样式有自己的设计），迁移时需目视核对。
- 浏览器端 `mount()` 会读 CSS 字体，SSR/Node 端渲染时需要自行保证字体可用，否则文字宽度可能不准。
