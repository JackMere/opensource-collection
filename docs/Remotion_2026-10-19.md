## 项目简介

Remotion 是「**用 React 代码做视频**」的框架：一段视频就是一个 React 组件树，当前播放到第几帧由 `useCurrentFrame()` 给出，画面据此渲染。因此视频可以接任意数据源、可以做条件逻辑、可以被单元测试、可以批量渲染上百万条。

官方定位在 2026 年已从「程序化视频」转向「**Video tools for the agent era**」——同一份 React 源码同时支撑三种工作流，且可随时切换：

- **Agent 生成**：编码助手直接写 React 组件出片；
- **交互编辑**：Studio 里拖拽调动画；
- **代码编程**：连数据、管复杂度。

React 代码是唯一事实源。

## 核心功能

1. **逐帧可寻址渲染**：`useCurrentFrame()` / `interpolate` / `spring` 驱动动画，天然确定性——同样输入必然产出同样视频。
2. **Remotion Studio**：本地可视化预览、时间轴拖动、参数实时调节（Interactivity）。
3. **渲染三路线**：
   - `@remotion/renderer`（Node.js API，本地/CI）
   - **Remotion Lambda**（AWS 分布式，海量批量）
   - CLI `npx remotion render`
4. **组件生态**：Elements、Effects、Shapes、Transitions、Sound Effects、Captions、Fonts 均是官方包，字幕/转场/音效不用自己造。
5. **嵌入能力**：`@remotion/player` 把视频播放器嵌进 Web 应用，可做交互式视频编辑器。
6. **Agent Skills**：官方维护 `remotion-dev/skills`（本库序号 19 已收录），提供 markup / render / captions / maps 等最佳实践，配 `npx skills add remotion-dev/skills` 使用。
7. **模板市场**：`npx create-video@latest` 直接起项目，官方 templates 站提供成片骨架。

## 安装与使用

```bash
# 新建项目（Node.js 已安装时）
npx create-video@latest

# 渲染
npx remotion render <composition-id> out/video.mp4

# 装官方 Agent Skills（配合 Claude Code / Codex / Cursor）
npx skills add remotion-dev/skills
```

前置：Node.js 18+、Chrome/Chromium headless（Remotion 会自动下载或复用系统浏览器）、FFmpeg（渲染层已内置所需能力）。

## 使用场景

- **数据驱动视频**：每天上百条个性化视频（报表、榜单、财报播报），React 模板 + 数据映射即可。
- **产品宣传片 / 功能演示**：组件化拼镜头，改文案改配色不用重剪。
- **设计系统资产**：把动效沉淀成组织内的动画组件库。
- **交互式视频应用**：用 Player 做可配置的视频生成器（用户填参数，实时出片）。
- **CI 里出片**：视频进版本管理，改代码即改片子，可回归比对。

## 优势与特点

- **代码即片子**：可复用、可 diff、可测试，团队协作方式与传统剪辑完全不同。
- **确定性渲染**：同输入同输出，适合批量与回归。
- **生态最完整**：字幕、转场、音效、字体、地图、Lottie 都有官方或一等公民包。
- **渲染规模可扩**：Lambda 能并行到成千上万条。
- **Agent 友好**：官方专门维护 skills 仓与 prompts 站，2026 年的重心明确偏向 AI 生成工作流。

## 注意事项

- **许可不是开源许可**：个人、非营利、≤3 人的营利公司可免费商用；**超过 3 人的营利公司必须买 Company License**（remotion.pro）。对外交付涉及商业主体时先确认资格，别默认「GitHub 上就是免费」。
- **必须写 React**：相比 HyperFrames 的纯 HTML，学习门槛与生成难度更高；agent 一次写对的大概率低于 HTML 方案。
- **本地渲染吃内存**：headless Chrome 逐帧截图，1080p 长片在 4G 内存机器上会吃紧，生产建议 Lambda 或大内存机。
- **不是剪辑软件**：没有时间轴 NLE 的素材管理、多轨混音、快捷键体系，做「精剪真人素材」不如传统工具。
- **不适合的场景**：一次性的短视频、需要大量实拍剪辑、团队里没人会 React——这几种用模板化工具或 HyperFrames 更划算。

## 与 HyperFrames 的关系

官方文档明确写了：HyperFrames 受 Remotion 启发，两者都用 headless Chrome + FFmpeg 渲染，区别在**授权模型**——Remotion 赌 React 组件，HyperFrames 赌人类和 agent 都能直接写的纯 HTML。HyperFrames 还提供 `/remotion-to-hyperframes` 单向迁移技能。选型时可以按「团队会不会 React」和「许可成本」两条来切。
