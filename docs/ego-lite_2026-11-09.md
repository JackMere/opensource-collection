## 项目简介

ego lite 是一个**为人和 AI Agent 共用而设计的 Chromium 浏览器**，不是"给浏览器套个自动化桥"。

它把 Agent 的任务放进独立的 **Space**（浏览器内的隔离工作区），Agent 在 Space 里跑自己的任务，你在自己的标签页里正常浏览，互不抢占；同时首个启动时可以选择迁移 Chrome 数据，Agent 直接继承你的登录态、Cookie、扩展和书签。

定位很明确：browser-use、agent-browser 这类工具本质是"桥"，需要一个现成浏览器被驱动，浏览器数据搬不过去、连接不稳、人和 Agent 抢控制权；ego lite 则是从内核开始就按"两个使用者"来设计的浏览器。

## 核心功能

1. **Space 隔离**：每个 Agent 任务一个独立工作区，不干扰用户当前浏览。
2. **继承真实登录态**：可选迁移 Chrome 数据，Agent 直接用你已登录的站点，不需要重新认证。
3. **Snapshot 结构化快照**：把当前页面转成结构化文本（每个可交互节点带 `role`、`name`、`refId`），Agent 读文本决定下一步，而不是看图。
4. **三种定位方式**（按优先级）：`@21` / `ref=21` 快照引用 → `loc=role:button[name='Sign in']` / `loc=css:` / `loc=href:` 语义定位 → 坐标点击（仅画布/视觉类页面兜底）。
5. **Playwright 风格 API**：`page.click()`、`fill()`、`hover()`、`dragAndDrop()`、`mouse.*`、`keyboard.*`、`screenshot()`。
6. **快照作用域**：`snapshot()` 取视口，`{scope:"full_page"}` 取整页，`{scope:"subtree", root:"@12"}` 只取某棵子树；快照包含普通 iframe 与跨域 OOPIF 内容。
7. **零成本零配置**：本地运行，数据和 Cookie 留在设备上；数据采集刻意做窄（只报"是否设为默认浏览器"这类信号）。

## 安装与使用

三种方式任选：

```bash
# 1) 直接下载 App（macOS / Windows，Linux 在路线图上）
# 2) 只装 Agent 技能
npx skills add citrolabs/ego-lite
# 3) 让 Agent 自己装
#    把这句丢给 Agent：
#    Set up ego lite for me: https://github.com/citrolabs/ego-lite
```

Agent 侧调用：

```bash
ego-browser skill          # 先打印与已安装版本匹配的使用指南
```

```js
// 拿快照 → 用 ref 操作 → 再拿快照
await page.snapshot();                       // 视口，节点形如 [ref=21] button "Sign in"
await page.fill("@21", "user@example.com");
await page.click("loc=role:button[name='Sign in']");
await page.snapshot({ scope: "full_page" });
```

## 使用场景

- **Agent 做真实网页操作**：登录、填表、点按钮、抓数据，复用你已有的登录态。
- **Web 应用测试 / QA / Dogfooding**：Agent 在 Space 里跑一遍流程，你同时在主窗口正常工作。
- **需要人机并行的场景**：Agent 跑自动化时你要继续用同一个浏览器（这是它相对 browser-use 的核心差异）。
- **画布类应用**：没有 DOM 语义时退回截图 + 坐标点击。

## 优势与注意事项

**优势**
- 人机隔离做在浏览器内核层（Space），不是靠多开 profile 硬隔离。
- 继承真实登录态，省掉"给 Agent 单独造账号"的麻烦。
- 快照是结构化文本，**token 消耗比截屏视觉方案低**，这也是它宣称"更快、更省 token"的原因。

**注意**
- **仅 macOS / Windows**，Linux 仍在 roadmap——服务器上跑不了，只能用在桌面端。
- 快照只覆盖视口，长页面要显式 `full_page` 或 `subtree`，否则 Agent 会"看不见"下面的内容。
- **继承了你的登录态 = 继承了你的权限**：给 Agent 用的账号建议单独收敛，别把管理员账号的浏览器数据直接迁移过去。
- 坐标兜底路径（`mouse.click(x, y)`）在页面布局变化后极易点错，能不用就不用。
- 22k star 属于近期快速增长的项目（2026-04 建仓），接口仍在演进（技能版本 2.2.0）。
