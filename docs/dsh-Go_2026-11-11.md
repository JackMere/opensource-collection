## 项目简介

dsh-Go 是 **DeepSeek Harness（dsh）的 Android 客户端**，2026-10 开源，上线一周多就在 Trendshift 拿到全语言日榜第一。

它解决的是两个具体问题：

1. **手机上本机跑**：App 内置 Linux 环境（免 Root、免 Termux），dsh 直接跑在手机里，出门也能干活。
2. **遥控电脑上的 dsh**：电脑上的 DSH 通过 `dsh_remote` 客户端一键切过来接着用，手机上看到的是同一个会话。

另外它还带两个吉祥物桌宠「Deepy」和「鲸娘」——干活时敲代码、做完空翻、等确认时举手，打开「App 外显示」还能跟到桌面。

## 核心功能

1. **内置 Linux 运行时**：`runtime/` 目录负责 Linux 环境打包、引擎补丁和 App 桥接，无需 Termux 或 root。
2. **双模式**：本机运行（`dsh_client`）与远程遥控桌面 DSH（`dsh_remote`）并存，可随时切换。
3. **插件体系**：`sdk/plugin-kit/` 是原生插件作者工具包（未发 npm，需在仓库内使用），`examples/plugins/` 有示例。
4. **桌面宠物**：Deepy 与鲸娘跟随工作状态做动作，可外显到系统桌面。
5. **配套站点与社区**：论坛 `forum.dshtui.com`、QQ 群，插件开发文档在 `docs/plugins/`。

## 安装与构建

**普通用户**：从 GitHub Releases（或官网下载页）拿最新 APK，常见手机选 **arm64** 包。

> ⚠️ 装过签名不同的早期测试包时**不能直接覆盖安装**，必须先卸载——而卸载会清空对话、Linux 环境和设置。

**从源码构建**（Linux x86_64）：

```bash
git clone https://github.com/ccch1mneyyy/dsh-go.git
cd dsh-go

bash tooling/setup-toolchain.sh        # 装 JDK 17、Flutter 3.47.7、Android SDK/NDK 到 ~/dev
source tooling/env.sh
flutter --version && java -version

bash runtime/build-runtime.sh arm64-v8a
DSH_BETA_TOKEN_FILE= bash tooling/build-apk.sh -f arm64 --keep-daemon
# 产物：app/build/app/outputs/flutter-apk/app-arm64-release.apk
```

未配置 `app/android/key.properties` 时，本地 release 构建使用 **debug 签名**，无法覆盖官方包。

## 使用场景

- **离开电脑也能盯 Agent**：通勤、出差时用手机看会话、下指令、收结果。
- **手机本机跑轻量任务**：不想让电脑长时间开机，用手机内置 Linux 环境跑短任务。
- **远程接管桌面会话**：电脑上的 dsh 跑到一半要出门，手机切过去继续。
- **给 agent 写手机端插件**：基于 `sdk/plugin-kit` 扩展原生能力。

## 优势与注意事项

**优势**
- 免 Root、免 Termux，开箱即用；对非极客用户友好。
- 本机与远程双模式，覆盖"没电脑"和"电脑在家"两种场景。
- 社区活跃（一周多 19.5k star），更新频繁。

**注意**
- **AGPL-3.0**：如果你要把它的代码集成进自己的服务并对外提供，会触发 AGPL 的开源义务；商用前先看 `ASSETS.md` 和再发布条款——**名称、标识、吉祥物不在开源授权范围内**。
- **仅供 Android**，iOS / 鸿蒙尚未发布。
- 内置 Linux 环境意味着手机上有一整套可执行空间，**不要在存有敏感资料的主力机上随意装来源不明的 APK**；只从官方 Releases 下载并核对签名。
- 远程遥控依赖 DSH Remote 的网络连通性，跨公网使用时注意传输安全。
- 项目年轻（2026-10-25 建仓），接口与插件 API 可能变动。
