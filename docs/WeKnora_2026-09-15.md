## 项目简介

WeKnora（维娜拉）是腾讯开源的、基于大语言模型（LLM）的**企业级知识管理框架**，专为文档理解、语义检索与智能推理场景打造。它围绕三大核心能力构建：**RAG 快速问答**用于日常知识查询，**ReAct Agent 智能推理**自主编排知识检索、MCP 工具、技能沙箱与网络搜索完成多步任务，**Wiki 模式**则让 Agent 从原始文档中自治生成相互链接的 Markdown 知识库与可视化知识图谱。

它同时是**微信对话开放平台**（chatbot.weixin.qq.com）的核心技术框架——不是实验性项目，而是在真实业务中运行的生产级系统。全流程模块化设计，大模型、向量数据库、存储等组件均可灵活替换，支持本地与私有云部署，数据完全自主可控。

## 核心功能

1. **智能对话三模式**
   - **ReAct 渐进式多步推理**：自主编排知识检索、MCP 工具、技能沙箱与网络搜索
   - **RAG 快速问答**：基于知识库的检索增强生成，快速准确
   - **Wiki 模式**（v0.5.0 正式版）：Agent 从原始文档自治生成结构化、相互链接的 Markdown Wiki 页面与知识图谱，支持浏览器内人工编辑、页面版本历史、行级 diff 与一键回滚

2. **分块编辑与版本历史**：检索分块可像文档一样在线编辑，保留逐版本快照，支持 diff 与一键回滚，编辑后自动重建索引

3. **跨会话长期记忆**：记忆 profile / preference / fact / task / interest，支持自动抽取、用户确认与按需 `search_memory`

4. **技能目录与沙箱**：空间技能目录（ClawHub / SkillHub / git / zip）安装到会话级 Docker / E2B / Cube 沙箱，支持 `shell_exec`、文件工具、产物收集、按配置网络策略

5. **多源数据接入自动同步**：飞书知识库、飞书云盘、Lark、GitLab、腾讯 IMA、Notion、语雀、RSS（支持增量与全量同步）

6. **文档格式覆盖广**：PDF、Word、Txt、Markdown、HTML、EPUB、MHTML、图片、CSV、Excel、PPT、JSON、XMind；Office 文档由 **anydoc** 在 Go 进程内解析

7. **检索策略**：BM25 稀疏召回 / Dense 稠密召回 / GraphRAG 图谱增强 / 父子分块 / pgvector HNSW 加速（1024 维）/ 多维度索引

8. **企业级治理**：多空间 RBAC（Owner / Admin / Contributor / Viewer 四级角色矩阵 + 资源归属 + 空间审计日志）、权限范围 API Key 与 Principal 模型、Langfuse 全链路可观测性、运行时任务队列面板 + Worker 池治理

9. **IM 与发布集成**：企业微信 / 飞书 / Lark / QQBot / Slack / Telegram / 钉钉 / Mattermost / 微信 / 云之家；网站嵌入 Widget（域名白名单 + 限流 + 安全模式 Token 交换）

10. **端到端测试**：检索 + 生成全链路可视化，评估召回命中率、BLEU / ROUGE 等指标

## 安装与使用

**环境要求**：Docker & Docker Compose、Git

```bash
# 1. 克隆并配置
git clone https://github.com/Tencent/WeKnora.git
cd WeKnora
cp .env.example .env   # 按需编辑 .env，详见文件内注释

# 2. 启动核心服务
docker compose pull
docker compose up -d

# 3. 访问 Web UI
# http://localhost
```

**可选服务（Compose Profile，可叠加）**

```bash
# 全部功能
docker compose --profile full pull && docker compose --profile full up -d

# 知识图谱（Neo4j）
docker compose --profile neo4j pull && docker compose --profile neo4j up -d

# 对象存储（MinIO）
docker compose --profile minio pull && docker compose --profile minio up -d

# 链路追踪（Langfuse）
docker compose --profile langfuse pull && docker compose --profile langfuse up -d
```

**服务地址**：Web UI `http://localhost` ｜ 后端 API `http://localhost:8080` ｜ Langfuse `http://localhost:3000`

**开发模式（免重建镜像）**

```bash
make dev-start      # 启动基础设施
make dev-app        # 启动后端（Air 热重载）
make dev-frontend   # 启动前端（热重载）
```

**核心容器构成（默认 profile）**：`weknora-ui` + `weknora-app`(Go) + `weknora-docreader` + `weknora-sandbox` + **ParadeDB**(PG17，pgvector + BM25) + `redis:7` + `searxng` + `minio`；可选叠加 Neo4j / ClickHouse(Langfuse) / Qdrant / Milvus / Weaviate / Doris。

## 使用场景

1. **企业知识库建设**：把散落在飞书、GitLab、Notion、语雀的文档统一沉淀为可问答的知识资产
2. **文档智能问答**：面向 PDF/Word/Excel/PPT/图片的 RAG 问答，带引用浮层与来源区分（网络 / 知识库）
3. **规范与制度版本追溯**：分块编辑 + 版本历史 + diff 回滚，适合需要追踪条款变更的场景
4. **自治知识库演进**：Wiki 模式让 Agent 自动沉淀结构化知识页并生成知识图谱，人工可编辑校准
5. **多步复杂任务自动化**：ReAct Agent 结合 MCP 工具与沙箱执行，完成检索 + 计算 + 文档生成的复合任务
6. **IM 内知识服务**：接入企业微信 / 飞书 / Slack，员工在 IM 内直接提问
7. **程序化集成**：通过 MCP Server 或权限范围 API Key 接入自有系统

## 优势与特点

### 优势
- **腾讯官方出品且经过生产验证**：微信对话开放平台的核心技术框架，非实验项目
- **三能力一体**：RAG 问答 + Agent 推理 + 自维护 Wiki，覆盖从查询到沉淀的完整链路
- **组件高度可替换**：模型 / 向量库 / 存储 / 网络搜索均为可插拔，不绑定单一厂商
- **数据自主可控**：支持本地与私有云部署，MIT 系宽松授权（README 标注）
- **企业级完备度高**：多空间 RBAC + 审计日志 + 权限范围 API Key + Langfuse 全链路可观测
- **生态集成丰富**：10 类 IM、8 类数据源、8 种向量库、20+ 模型厂商
- **活跃维护**：⭐23.2K，创建至今迭代到 v0.8.0，近期提交密集

### 注意事项
- **资源开销较大**：默认即 7+ 容器（含 ParadeDB、Redis、MinIO、SearXNG），开启图谱/追踪后需 Neo4j、ClickHouse 等，对机器配置有要求
- **信创环境适配未知**：镜像来自 Docker Hub 官方仓库，未声明 ARM64 / 麒麟 / 达梦 / 国密支持，信创交付场景需先验证
- **许可证需核对**：README 标注 MIT，但仓库 LICENSE 为腾讯自定义复合授权文件（含第三方 MIT/Apache/BSD/GPL 声明），商用前建议法务确认
- **部署依赖 Docker**：非 Docker 环境需自行构建，上手成本高于纯 CLI 工具
- **项目迭代快**：版本演进频繁（v0.1 → v0.8.0 一年内完成），升级需留意 CHANGELOG 的破坏性变更
