## 项目简介

Archify 是一个**给 AI Agent 用的技能**（不是普通的库）：你把一句描述、一份方案、或者一个代码仓库丢给 Agent，它按 Archify 的规范产出一个**可交互的单文件 HTML**——架构图、流程图、时序图，或者一整页"带结论的解释页（explainer）"。

官方定位是「把任何你想理解、规划或分享的东西变成可交互的视觉」：场景不限于系统架构，也包括行程表、学习地图这类非技术内容。支持 Claude Code、Codex CLI、Cursor、OpenCode 四类客户端，skills.sh 上装量 13 万+。

## 核心功能

1. **两种产出形态**：单一**架构/流程图**，或**一页式解释页**（结论在前，每个面板回答一个问题，图与步骤并列并联动高亮）。
2. **可交互、可分享**：一个 HTML 文件自带 4 种样式、明暗主题，可导出 PNG / WebP / JPG 长图或打印成 PDF。
3. **有据可查**：解释页的每条结论可挂编号引用，仓库片段固定到具体 commit，点开是源码卡片——这点对技术评审很关键。
4. **无需仓库起步**：从一句话开始，也可以让 Agent 读仓库后产出"有源码依据"的架构图。
5. **局部改图**：对着某个面板继续追问（"加认证链路""高亮缓存未命中路径""换成浅色主题"），只改相关部分。
6. **多语言文档**：README 提供简体中文、日文、韩文版本。

## 安装与使用

把这句话发给 Agent（它会自己读 `llms.txt` 完成安装）：

```text
Install Archify for me by reading https://raw.githubusercontent.com/tt-a1i/archify/main/llms.txt
```

然后用自然语言出图：

```text
Use Archify to diagram a web request: Browser calls the API,
the API checks Redis, and a cache miss queries PostgreSQL and fills the cache.
```

继续追问即可迭代：`Add authentication`、`Highlight the cache-miss path`、`Switch to the light theme`。

解释页用法：

```text
Use Archify to answer as one page: our API's P99 went from 80 ms to 600 ms
while the mean barely moved. What is the likely cause, and how should we investigate?
```

## 使用场景

- **技术方案评审**：把一段文字方案变成可点开的架构图，评审批注直接落在图上。
- **新人理解老系统**：让 Agent 读仓库后出"带源码依据"的架构图，节点可追溯到文件。
- **故障复盘 / 性能分析**：用解释页形态，先给结论再给证据链（P99 抖动这类问题特别合适）。
- **对外交付**：单文件 HTML，发给客户/同事双击就能看，不需要部署。
- **给非技术读者的说明材料**：它本身支持非技术场景（行程、学习路径）。

## 优势与注意事项

**优势**
- 产出是**单文件 HTML**，零部署、可离线、可导出多种格式，分享成本极低。
- 专为 Agent 设计（走 `llms.txt` 自装），与 Claude Code / Codex / Cursor / OpenCode 都能配合。
- 解释页的"结论 + 引用 + 源码锚点"结构，比一次性大图更适合做技术决策记录。

**注意**
- **它不是库，是技能/工作流**：核心价值在 Agent 侧的生成规范，不写 Agent 就用不上。
- 生成质量取决于所选模型能力——复杂系统图建议用强模型，便宜模型容易出"结构对但细节错"的图。
- 单文件 HTML 内含图数据，**别把含内部 IP / 账号 / 接口地址的图直接公开分享**。
- 93k star 属于爆发式增长（2026-04 建仓），生态插件多（如 dsh-archify 移植版），选型时认准 `tt-a1i/archify` 主仓库。
