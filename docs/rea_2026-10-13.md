## 项目简介

"Reverse engineer anything with agents"：Agent 通过 MCP 调用 REA 检查目标、追踪相关代码，返回带证据的发现，Agent 再追问、解释行为或写实现验证。从应用行为到原生二进制全覆盖的逆向工程 Agent 工具箱。

## 核心功能

1. MCP 服务 + CLI 双形态，Agent/终端均可调
2. 原生二进制：伪代码/汇编/符号/调用引用（需 Ghidra、IDA 或 Hopper）
3. 应用层：JS/Electron（模块/路由/IPC）、Android APK（JADX 反编译）、.NET（CIL）、Flutter、固件
4. 运行时：进程行为捕获、录制崩溃、网络抓包（HAR/SAZ）、逻辑信号
5. 全程证据回执：返回代码、引用与未知项，不编结论

## 使用场景

- 闭源 SDK/竞品行为分析（API 行为、埋点、加解密）
- 存量二进制问题定位（崩溃、兼容性）
- Electron/APK 应用结构梳理与 IPC 链路追踪
