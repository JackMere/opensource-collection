## 项目简介

用 Claude Code Skills 做的中文口播视频剪辑 Agent，以 Codex Marketplace Plugin 形态分发。切的是中文语境的痛点：口播节奏、中文断句、字幕排版。恒华整合仓（HHQC-369/codex-video-skills）核对后的当前有效上游（替代已失效的 Ceeon/videocut-skills）。

## 核心功能

1. 中文口播视频自动剪辑
2. Claude Code Skills + Codex Marketplace 双形态
3. 口播节奏与中文字幕专项优化

## 使用场景

- 中文知识口播、课程视频粗剪
- 团队内以 Marketplace 插件统一分发剪辑能力

## 优势与注意事项

- 优势：Apache-2.0；中文场景唯一成建制的选项；10-10 仍在更新
- 注意：中文断句质量依赖底层转录模型；精剪仍需人工终验
