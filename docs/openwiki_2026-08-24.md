## 项目简介

OpenWiki 是 LangChain 官方出品的自维护 Wiki CLI：一个 Agent 读取你的代码库/个人知识，综合生成一份**互联的 Markdown Wiki** 供你拥有，并在每次代码变更后持续更新。它专为「让 Agent 作为记忆读取」而设计，同时附带一个交互式可视化器供人类浏览探索。

## 核心功能

1. **Agent 编写的文档**：由 Deep Agents 文档 Agent 生成，保持文档与代码同步准确
2. **两种模式**：
   - `code`：为代码仓库生成 Wiki
   - `personal`：为个人知识库生成 Wiki
3. **13 种模型提供商**：开箱即用，覆盖 OpenAI、Anthropic、Bedrock、Gemini 及任意 OpenAI 兼容网关
4. **编码 Agent 集成**：可直接在 Codex 和 Claude Code 内运行，复用宿主模型与仓库工具
5. **Grounded Claims（可溯源声明）**：将关键事实追溯到带版本的源码证据，证据变更时自动提示需确认/重写/退役
6. **9 种内置连接器**：Custom MCP、Notion、Slack、Gmail、X、Web Search、Hacker News、LangSmith、本地 git 仓库
7. **交互式可视化器**：把任意 Wiki 变成可探索的节点图
8. **自动更新**：通过 GitHub Actions / GitLab CI / Bitbucket Pipelines 持续同步
9. **OKF v0.2 开放知识格式**：输出可移植的 Open Knowledge Format，含验证过的 Mermaid 图与可复现的生成溯源

## 安装与使用

```bash
# 全局安装 CLI（需要 Node.js 22+）
npm install -g openwiki

# 为代码库生成 Wiki
openwiki code

# 为个人知识生成 Wiki
openwiki personal
```

## 使用场景

1. **代码库文档化**：为大型仓库自动生成并持续维护可读的 Markdown 文档
2. **Agent 记忆库**：为 Coding Agent 提供可读取、随代码变更更新的「长期记忆」Wiki
3. **个人知识库**：连接 Notion/Slack/Gmail 等，沉淀个人知识为结构化 Wiki
4. **团队文档自动同步**：接入 CI 后，每次提交自动刷新 Wiki
5. **文档可视化**：用交互式节点图浏览代码库依赖与结构

## 优势与特点

### 优势
- LangChain 官方出品，社区活跃（⭐15.6K）
- 文档自维护，无需人工持续整理
- 多模型、多连接器，生态完善
- 支持 Codex / Claude Code 原生集成
- OKF 开放格式，可移植、可发布为静态站点

### 注意事项
- 需要 Node.js 22+ 运行环境
- 依赖 LLM 生成，可能产生 token 成本
- 中文代码注释/文档的生成质量取决于所用模型
- 项目较新（2026-06 创建），生态仍在快速演进
