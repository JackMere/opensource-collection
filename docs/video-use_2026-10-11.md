## 项目简介

browser-use 团队出品的对话式视频剪辑 Agent 框架："Edit videos with coding agents"。编码 Agent 直接操作视频：转录、剪切、字幕、调色、动画叠加。把剪辑从时间线软件里的手工活变成可对话、可脚本化的 Agent 任务。

## 核心功能

1. 对话式自动剪辑（自然语言描述要什么成片）
2. 转录、剪切、字幕、调色、动画叠加全链路
3. 面向编码 Agent 的调用接口，可编排进自动化流程

## 使用场景

- 口播/访谈粗剪自动化
- 批量短视频二剪（字幕+调色+包装一条龙）
- 团队协作：Sidneyfad/linxiao-video-cut 把它搬进浏览器即开即用

## 优势与注意事项

- 优势：MIT 协议；browser-use 团队背书；28K⭐ 生态位头部
- 注意：重剪辑需要 FFmpeg 等本地依赖；精剪审美仍需人工终验
