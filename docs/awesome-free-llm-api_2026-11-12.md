## 项目简介

**中文**的免费大模型 API 导航，面向国内开发者，收录粒度比英文清单细。README 约 93KB，173 行表格，结构分为四层：

1. **匿名模型（Stealth）**：无需登录、匿名可用的模型接口
2. **模型免费渠道索引**：按模型系列反查——DeepSeek / GLM / Qwen / 其他国产 / 海外，回答"我想用某个模型，哪里免费"
3. **免费渠道一览**：按渠道类型分——海外官方免费层 / 中国平台 / 聚合与网关 / 限时免费 / **小型网关（谨慎）** / 客户端内免费（无公开 API）
4. **免责声明 + 参与贡献**

与英文清单的思路差异：英文版按"提供商"组织，这份按"**模型 → 哪里有免费额度**"组织，更贴近实际用法。

## 核心功能

1. **模型反查表**：给定模型名（如 DeepSeek V4、GLM-5、Qwen3）直接列出可用的免费渠道。
2. **区分渠道性质**：把"官方免费层"、"聚合网关"、"限时免费"、"小型网关"分开列，并且明确标注**哪些要谨慎**——这点在同类清单里少见。
3. **标注坑点**：会写细节，例如"额度不可提现""key 默认 6 个月有效期""RPM + TPM + 余额三重限流""建 key 时选错分组价格差 20 倍"。
4. **客户端内免费单列**：明确区分"App 里能用"和"有公开 API 能用"，避免照抄后调不通。
5. **中文语境**：国内平台可达性、注册方式、实名要求都按国内实际情况写。

## 使用方式

## 使用场景

- **国内环境找免费额度**：比英文清单更贴合国内平台（阿里百炼、硅基流动、智谱、ModelScope 等）。
- **按模型反查渠道**：想用某个具体模型（如 DeepSeek V4.1 Flash）时直接查哪里免费。
- **避开坑渠道**：作者标注的"小型网关（谨慎）"能帮你过滤掉随时关停的中转站。
- **接 New API 前做尽调**：判断某渠道是官方还是二手中转。

**优势**

- **明确标注风险渠道**，不粉饰。
- 按"模型反查"组织，比按厂商组织更贴合实际使用。

**注意**
