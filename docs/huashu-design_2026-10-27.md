## 项目简介
在 Agent 里打一句话，拿回一份能交付的设计：网页、App 原型、可编辑 PPTX、动画、信息图。HTML-native 的设计 Skill，跨 Agent 通用（Claude Code、Cursor、Codex、OpenClaw、Hermes 都能装）。3 到 30 分钟可交付，支持喂品牌资产（logo、色板、UI 截图）或零资产冷启动。

## 核心功能
1. 六选三方向：先出六张缩略图，再挑三版做成真稿，保证不撞脸、不出 AI slop。
2. 84 种带样张的风格库：新增 App、中文与东亚分区，每种风格都有样张可对。
3. 参照先行：`ref_board.py` 把现实参照作品截图成参考板，Agent 亲眼看过再动手。
4. 设计体检：只量事实的检查（如两版首屏撞图会自动换掉一版）。
5. 外观账本：记住你做过什么样子（如最近 6 个交付 5 个无衬线标题，新版就挑宋体），项目之间不长一个样。

## 安装与使用
```bash
npx skills add alchaincyf/huashu-design
```
装上后在 Agent 里一句话提需求即可，如「给《富岳三十六景》做一个线上展览网站」「做一个观鸟记录 App 的原型」。发布片剪辑用姊妹项目 `alchaincyf/huashu-motion`。

## 使用场景
- 产品发布页/活动页、App 可点击原型、讲座/科普 PPT、信息图，一句话出稿。
- 团队缺设计师时兜底出"大厂设计团队观感"的交付物；有设计师时做快速多方向发散。
