## 📖 使用说明

1. **自动收录**：发送任意开源项目链接（GitHub/GitLab/技术工具站点等），系统自动解析项目信息并归档
2. **分类规则**：
   - 每个项目自动标记「领域分类」和「用途分类」双维度标签
   - 新领域/新用途自动创建分类区块，无需人工干预
   - 单个项目支持归属多个分类
3. **详细资料**：每个项目在 `docs/` 目录下有独立详情文档，包含完整的项目介绍、技术栈、部署方式、适用场景等信息
4. **检索方式**：可通过标签检索区快速查找对应领域/用途的项目，也可通过汇总表搜索
