## 📖 使用说明

1. **自动收录**：发送任意开源项目链接、技术工具站点、优质资源地址（GitHub/GitLab/技术站点等），系统自动解析内容并归档
2. **分类规则**：
   - 每个收录项自动标记「领域分类」和「用途分类」双维度标签
   - 新领域/新用途自动创建分类区块，无需人工干预
   - 单个项目支持归属多个分类
3. **详细资料**：每个收录项在 `docs/` 目录下有独立详情文档，包含完整介绍、使用场景、优劣总结
4. **检索方式**：可通过标签检索区快速查找对应领域/用途的项目，也可通过汇总表搜索
